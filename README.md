# Garis Arcade

Arcade game hub built with [KorGE](https://korge.org/) (Kotlin Multiplatform).

- Engine: KorGE 6.0.0
- Targets: Android (JVM), Desktop (JVM)
- Release: GitHub Actions builds a signed APK on every `v*` tag

## Build locally

```bash
./gradlew :androidApp:assembleDebug
```
